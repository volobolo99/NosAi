# Security Policy

## Supported versions

The `main` branch is the supported development line. Released versions are supported according to the release notes and security advisories published for NosAi.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues. Report security problems privately to the repository owner through GitHub's private security reporting features when enabled for the repository.

Include:
- affected component and version/commit;
- reproduction steps or a minimal proof of concept;
- impact assessment;
- any suggested mitigation.

NosAi CI continuously performs dependency auditing, static security analysis, CodeQL/security checks, and SBOM generation where configured. Security findings must be reviewed before release.
