# G3.14 — Live NosTale Observation

G3.14 introduces the first live-runtime data path, deliberately limited to
read-only observations supplied by a user-controlled telemetry bridge.

## Purpose

Collect real runtime observations for NosAi model development and validation
without granting the agent the ability to control the game.

## Boundary

`NosTale telemetry bridge -> NosTaleLiveObserver -> bounded observations -> Telemetry/Test Center`

## Explicitly disabled

- game input automation;
- process injection or code modification;
- command execution;
- network control;
- bypass of client protections.

`execution_enabled` is hard-coded false. This gate therefore makes live data
collection available while preserving the existing runtime safety boundary.

## Exit criteria

CI, regression, safety and benchmark gates must pass before merge. Any future
write/control capability requires a separate gate and explicit safety review.
