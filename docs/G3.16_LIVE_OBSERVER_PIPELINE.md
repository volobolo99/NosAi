# G3.16 — Live Observer to AI Dataset Pipeline

G3.16 connects the certified read-only live observer path to the validated dataset recorder.

## Flow

`NosTale Live Observer -> LiveObservationPipeline -> LiveDatasetRecorder -> AI dataset`

## Guarantees

- observations only; no action emission;
- explicit session correlation;
- validation and bounded storage are inherited from G3.15;
- invalid observations are rejected and counted;
- pipeline statistics expose accepted/rejected ingestion;
- no training or runtime control is performed here.

Real NosTale control remains disabled. CI and Test Center certification are required before this gate is considered complete.
