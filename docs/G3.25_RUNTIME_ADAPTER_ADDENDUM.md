# G3.25 Runtime Adapter — Addendum

The repository already contains a legacy `nosai.runtime.adapter` dry-run contract. G3.25 therefore adds the layered observation adapter under `app.client.runtime_adapter` rather than replacing the legacy API.

Modes: `mock`, `replay`, `sandbox`, `real`.

The `real` mode requires explicit dependency injection of the existing `ClientAdapter` contract and remains observation-only. No action execution, process injection, memory patching, input automation, network control, or protection bypass is introduced by G3.25.

This separation preserves backward compatibility while allowing later gates to compose Model Registry, Sandbox Inference, and runtime observation without coupling them to a legacy interface.
