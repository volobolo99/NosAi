# G3.22 — Offline Training Foundation

G3.22 establishes a deterministic foundation for offline model training from recorded inference/dataset samples.

## Pipeline

`Recorded Dataset -> deterministic split -> baseline training -> validation/test metrics -> checksum/report`

## Guarantees

- deterministic ordering and dataset digest;
- explicit train/validation/test partitions;
- reproducible baseline score;
- invalid configuration is rejected early;
- no runtime control, process injection, input automation, network control, or protection bypass;
- no model is deployed or connected to the game runtime by this gate.

## Exit criteria

CI, regression, dependency/SBOM, safety and benchmark gates must pass before merge.
