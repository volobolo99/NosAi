# G3.25 — Runtime Adapter

G3.25 establishes a layered runtime boundary with four modes: `mock`, `replay`, `sandbox`, and `real`.

## Selected architecture

`RuntimeAdapter -> observation -> Sandbox Inference / planner`

The adapter normalizes observations and keeps the execution environment replaceable. `mock`, `replay`, and `sandbox` are suitable for deterministic testing. `real` requires an explicitly injected `ClientAdapter` and is observation-only.

## Safety boundary

The G3.25 adapter does not send actions, inject into processes, patch memory, bypass protections, or automate the client. The existing Windows NosTale adapter is also read-only and exposes only normalized client observations.

A future action-capable connector, if ever required, must be a separate reviewed gate rather than being added to this adapter.

## Exit criteria

CI, regression, dependency/SBOM, safety, benchmark and Test Center evidence must pass before merge.
