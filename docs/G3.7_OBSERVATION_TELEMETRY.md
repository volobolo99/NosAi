# G3.7 — Observation & Telemetry

G3.7 adds a bounded, deterministic telemetry layer around the certified
controlled sandbox.

## Pipeline

`PlayAi -> GuardAi -> DecisionFabric -> RuntimeAdapter -> ControlledSandbox -> Observation -> Telemetry -> Audit/Test Center`

## Invariants

- Telemetry is observational only and never grants authorization.
- Events are bounded in memory.
- Every event has a monotonically increasing sequence and session identity.
- Invalid identity/event fields are rejected.
- Timing is diagnostic only and never used as an authorization signal.
- No real NosTale execution or external process/input/network control is introduced.

## Exit criteria

Unit, integration, safety, regression and benchmark gates must be green before
merge. G3.7 does not change the real-runtime execution lock.
