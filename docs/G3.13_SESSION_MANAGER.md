# G3.13 — Runtime Session Manager

G3.13 adds a controlled lifecycle manager on top of the certified recovery state machine.

## Responsibilities

- explicit session identity;
- start/close lifecycle;
- heartbeat tracking;
- deterministic timeout detection;
- fail-closed transition to `DEGRADED` on timeout;
- safe, idempotent shutdown;
- persistent kill-switch invariant.

## Invariants

The session manager never executes runtime commands and cannot disable the kill switch.
Timeout is treated as a fault, not as permission to reconnect or execute. Real NosTale
execution remains disabled.

## Exit criteria

CI, regression, safety, benchmark and Test Center gates must be green before merge.
