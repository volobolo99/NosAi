# G3.23 — Model Registry

G3.23 provides an offline, integrity-first registry for model manifests and artifacts.

## Capabilities

- immutable identity by `model_id` + `version`;
- SHA-256 and byte-size artifact verification;
- dataset and evaluation lineage;
- schema/runtime compatibility metadata;
- lifecycle: `candidate -> validated -> promoted -> retired`;
- duplicate registration protection;
- deterministic manifest digest;
- filesystem persistence without loading or executing artifacts.

## Safety boundary

The registry never executes model artifacts and has no interface for game input, process injection, network control, protection bypass, or runtime automation. Promotion is metadata-only; runtime integration belongs to a later sandbox gate.

## Exit criteria

All regression, dependency/SBOM, safety, benchmark and Test Center gates must pass before merge.
