# Nos AI v4.8 — Reward Engine + Closed Learning Loop

v4.8 adds the two components selected for the next stage.

## Reward Engine

The reward model combines:
- goal progress
- success/failure
- intrinsic environment reward
- duration
- risk
- resource usage

Weights are configurable through `RewardWeights`.

## Learning Loop

`LearningLoop` connects the sandbox environment to the RL agent:

OBSERVE -> ACTION -> WORLD TRANSITION -> REWARD -> Q UPDATE -> NEXT STATE

It can run episodes and training batches and is designed so persistent memory,
Monte Carlo evaluations and strategy outcomes can be attached as additional
signals without coupling the RL core to a live client.

## Architecture

AI MEMORY -> WORLD MODEL -> GOAL PLANNER -> STRATEGY SIMULATOR / MONTE CARLO
-> REWARD ENGINE -> RL POLICY -> LEARNING LOOP -> EXPERIENCE -> AI MEMORY

The learning environment remains sandbox/replay based.
