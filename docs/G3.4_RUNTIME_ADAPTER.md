# G3.4 — Runtime Adapter Foundation

## Scope

G3.4 establishes the controlled boundary between Decision Fabric and a runtime.

### Certified path

`PlayAi -> GuardAi -> DecisionFabric -> RuntimeAdapter -> DryRunRuntime`

### Prepared path

`DecisionFabric -> NosTaleRuntimeAdapter (disabled)`

The NosTale adapter is a structural skeleton only. It cannot execute real game
actions in G3.4.

## Safety invariants

- Dry-run execution is deterministic.
- Empty actions are rejected.
- Runtime errors must not become implicit authorization.
- The NosTale adapter is fail-closed.
- No process/input/network automation is introduced by this gate.
- Real execution requires a later explicitly certified gate.

## Gate exit criteria

1. Runtime contracts exist and are provider-neutral.
2. Mock/Dry-Run behavior is covered by tests.
3. NosTale adapter boundary exists without real execution.
4. CI and Test Center certify the boundary before activation.
