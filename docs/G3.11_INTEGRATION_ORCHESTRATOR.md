# G3.11 — Controlled Runtime Integration Orchestrator

G3.11 composes the certified safety, state/recovery, sandbox and telemetry
boundaries into one deterministic orchestration path.

## Pipeline

`DecisionFabric -> Permission/Safety Gate -> State/Recovery -> NosTale Sandbox -> Observation/Telemetry -> Audit/Test Center`

## Invariants

- orchestration operates only on the controlled sandbox;
- unsafe actions are denied by policy;
- inactive/degraded states cannot execute commands;
- recovery ends in a safe state;
- telemetry is observational only;
- real NosTale execution remains disabled;
- no process injection, input automation or network control is introduced.

## Exit criteria

CI, regression, safety and benchmark gates must pass before merge. G3.11 is a
pre-integration milestone, not authorization for real runtime execution.
