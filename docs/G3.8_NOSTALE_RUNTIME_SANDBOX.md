# G3.8 — NosTale Runtime Sandbox

## Scope

G3.8 introduces a provider-specific NosTale runtime boundary for discovery and
simulation while preserving the certified execution lock.

## Pipeline

`DecisionFabric -> Permission Fabric -> RuntimeAdapter -> NosTaleSandboxAdapter -> Observation/Telemetry -> Audit/Test Center`

## Guarantees

- Discovery is non-invasive and does not control an external process.
- Discovery exposes only sandbox/observation capabilities.
- Simulation requires a discovered sandbox session.
- Simulation returns deterministic dry-run results.
- Real execution is hard-locked and returns a rejection.
- No process injection, keyboard/mouse automation, network control, or external
  runtime invocation is introduced by G3.8.

## Exit criteria

CI, Test Center, safety, regression and benchmark gates must be green before
merge. Any future real-runtime integration requires a separate explicitly
approved and certified gate.
