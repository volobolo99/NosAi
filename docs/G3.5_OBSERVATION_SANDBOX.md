# G3.5 — Observation-only Sandbox

G3.5 extends the certified G3.4 runtime boundary with an observation layer.

## Certified path

`PlayAi -> GuardAi -> DecisionFabric -> RuntimeAdapter -> Observation/Sandbox`

The sandbox is observation-only. It does not execute game actions, inject input,
control processes, or make network changes.

## Safety invariants

- Kill switch starts engaged and cannot be released in G3.5.
- Observations are bounded to prevent unbounded memory growth.
- Observation payloads are normalized deterministically.
- Runtime observations are data only; they cannot authorize execution.
- Real execution remains disabled until a later, explicitly certified gate.

## Exit criteria

- Observation buffer unit tests pass.
- Kill-switch invariants pass.
- Full existing regression suite remains green.
- CI/Test Center records the evidence.
