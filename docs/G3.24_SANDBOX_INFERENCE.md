# G3.24 — Sandbox Inference

G3.24 introduces a bounded offline inference boundary with deterministic request/output digests and auditable evidence.

## Boundary

`Model Registry -> InferenceSandbox -> structured output + evidence`

The sandbox does not load arbitrary model files, spawn processes, access the network, inject into processes, automate mouse/keyboard input, control the game client, or bypass protections.

## Controls

- input size limit;
- execution-time budget;
- structured success/failure evidence;
- request/model identifiers;
- input/output SHA-256 digests;
- latency measurement;
- stable evidence digest.

The timeout is enforced as a post-execution budget in this foundation; hard preemption/isolation belongs to a stronger process/container sandbox gate if required by later deployment.

## Exit criteria

CI, regression, dependency/SBOM, safety, benchmark and Test Center evidence must pass before merge.
