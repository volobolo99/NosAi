# G3.21 — Evaluation Harness

G3.21 adds a deterministic evaluation harness over recorded read-only inference outputs.

## Pipeline

`Dataset Replay -> Read-only Inference -> Evaluation Harness -> Metrics/Feedback -> Report`

## Guarantees

- deterministic dataset digest for identical valid samples;
- explicit valid/invalid sample accounting;
- bounded score and confidence metrics;
- measurable feedback coverage;
- no runtime commands or executable actions;
- malformed samples are isolated rather than executed.

## Safety boundary

The harness is analysis-only. It does not control NosTale, inject into processes, automate input, control the network, bypass protections, train models, or expose a runtime action interface.

## Exit criteria

CI, regression, dependency/SBOM, safety and benchmark gates must pass before merge.
