
# Nos AI v4.7 — World Model + Full Sandbox RL Environment

v4.7 implements both components requested for the next stage:

## World Model

A structured simulation state contains:
- character state
- entities
- map
- inventory
- quests/flags
- tick/time

`WorldModel.apply()` performs pure state transitions.

## RL Environment

`WorldRLEnvironment` exposes:
- reset()
- actions(state)
- step(state, action)
- reward(...)

The Q-learning agent can train directly against this sandbox.

## Learning loop

WORLD STATE
  -> available actions
  -> RL policy
  -> World Model transition
  -> reward
  -> next state
  -> Q update
  -> repeat

This is an offline/sandbox architecture. It does not connect the RL trainer
to a live game client and does not implement security-protection bypasses.

## Next evolution

The world model can progressively be populated from approved data/replay
sources, while the reward model can incorporate memory, Monte Carlo results,
goal progress and strategy outcomes.
