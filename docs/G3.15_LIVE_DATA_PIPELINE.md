# G3.15 — Live Data Pipeline & Dataset Recorder

G3.15 turns read-only live observations into bounded, validated records suitable for AI data preparation.

## Flow

`Live Observer -> validation -> UTC timestamp -> session correlation -> bounded recorder -> quality metrics`

## Guarantees

- records contain observations only, never executable commands;
- timestamps are timezone-aware and normalized to UTC;
- sessions are explicit;
- recorder capacity is bounded;
- invalid input is rejected;
- record IDs are deterministic hashes of session, timestamp and canonical payload;
- no model training or runtime control is performed by this component.

## Safety

G3.15 does not add game control, process injection, input automation, network control or protection bypass. Real runtime execution remains disabled.

## Exit criteria

CI, Test Center, safety, regression and benchmark gates must be green before merge.
