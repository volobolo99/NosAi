# G3.19 — AI Inference Read-Only

G3.19 introduces the first AI inference boundary over validated feature vectors.

## Guarantees

- input is limited to numeric feature data;
- non-finite and malformed values are rejected;
- score and confidence are bounded to `[0, 1]`;
- identical inputs produce identical outputs and digest;
- the component emits an inference result only, never an executable action;
- no runtime-control API is exposed by this component.

## Pipeline

`Live Observer -> Dataset Recorder -> Feature Extraction -> Read-Only Inference -> Evaluation`

## Safety

G3.19 does not control NosTale, inject into processes, automate input, control the network, bypass protections, or enable runtime execution. Real game control remains disabled.

## Exit criteria

CI, Test Center, safety, regression and benchmark gates must be green before merge.
