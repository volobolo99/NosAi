
# Nos AI v4.6 — Hierarchical Goal Planner + Reinforcement Learning

v4.6 adds both requested systems on top of v4.5.

## Hierarchical Goal Planner

High-level objectives are decomposed into dependency-aware subgoals.

Examples:
- EXP: resources -> area -> travel -> farm -> recover
- ITEM: identify -> sources -> select -> acquire
- QUEST: objective -> target -> travel -> complete
- PVM/PVP: assessment -> preparation -> engagement -> adaptation -> recovery

The executor only tracks readiness/completion. Actual execution remains behind
the existing adapter/command layer.

## Reinforcement Learning

A tabular Q-learning component is included for sandbox/replay training.

It learns:
- state/action values
- reward-driven preferences
- policy choices

`SandboxRLTrainer` deliberately accepts an injected environment. It does not
train against or control a live game client.

## Combined architecture

GOAL
 -> HIERARCHICAL GOAL PLANNER
 -> SUBGOALS
 -> CANDIDATE STRATEGIES
 -> MONTE CARLO / STRATEGY SIMULATOR
 -> STRATEGY ENGINE
 -> RL POLICY SIGNAL
 -> BEST PLAN
 -> EXECUTION ADAPTER
 -> OBSERVATIONS
 -> AI MEMORY v2 / SQLite
 -> learning feedback
