# G3.18 — AI Dataset Replay & Quality

G3.18 adds deterministic replay and basic quality reporting for recorded observation datasets.

## Flow

`Recorded observations -> quality report -> deterministic replay -> reproducibility digest`

## Guarantees

- replay consumes observation records only;
- identical session and records produce an identical digest;
- empty inputs are rejected;
- malformed/empty records are counted as invalid;
- no runtime commands are invoked;
- no model training or game control is performed.

## Safety

This gate remains observation/data-only. Real NosTale execution and automated game control remain disabled.
