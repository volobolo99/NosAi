# G3.6 — Controlled Sandbox & Runtime Contract

## Certified scope

G3.6 adds a deterministic sandbox boundary between the runtime adapter and any
future external runtime. It supports lifecycle control, bounded observations,
audit events, and simulated runtime results.

## Safety invariants

- The kill switch is engaged for the lifetime of the sandbox.
- Simulation is dry-run only.
- Observations never authorize runtime execution.
- Sessions have explicit CREATED → ACTIVE → CLOSED lifecycle.
- Observation storage is bounded.
- No process, keyboard/mouse, network-control, or external-runtime invocation.
- Closed sessions cannot be restarted.

## Pipeline

`PlayAi → GuardAi → DecisionFabric → RuntimeAdapter → ControlledSandbox → Observation/Audit → Test Center`

## Exit criteria

Unit, integration, safety, regression and benchmark gates must be green before
merge. Real NosTale execution remains outside G3.6.
