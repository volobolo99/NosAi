# G3.17 — Data Quality & AI Feature Extraction

G3.17 converts validated live observations into deterministic, versioned numeric feature vectors for downstream AI components.

## Pipeline

`Live Observer -> Dataset Recorder -> Feature Extractor -> AI-ready Feature Vector`

## Guarantees

- schema is explicitly versioned;
- only finite numeric values from the approved observation fields are emitted;
- malformed values are excluded rather than guessed;
- a quality ratio reports feature completeness;
- extraction is deterministic for the same inputs;
- this component does not issue runtime commands or authorize execution.

## Safety

No game control, process injection, input automation, network control or protection bypass is introduced. Real NosTale execution remains disabled.
