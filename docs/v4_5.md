
# Nos AI v4.5 — Monte Carlo Planning + Persistent AI Memory

v4.5 adds both requested systems.

## Persistent memory

`SQLiteMemoryStore` persists:
- observations
- facts
- inferences
- strategy experiences

The schema is indexed for sessions/events/strategy learning and can later be
replaced by another repository implementation.

## Monte Carlo planning

`MonteCarloPlanner` evaluates candidate strategies through repeated stochastic
sandbox rollouts.

It calculates:
- success probability
- expected reward
- expected duration
- expected risk
- 95% confidence interval

The transition model is injected, so the planner remains independent from the
live execution layer.

## Combined architecture

OBSERVE
  -> AI Memory v2 / SQLite
  -> WORLD STATE
  -> candidate strategies
  -> StrategySimulator / Monte Carlo Planner
  -> scored expected outcomes
  -> StrategyEngine
  -> Task Plan
  -> authorized execution adapter

The Monte Carlo implementation is a sandbox/replay planning component; it
does not implement protection bypasses or direct live-game control.
