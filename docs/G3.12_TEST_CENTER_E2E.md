# G3.12 — Test Center End-to-End

G3.12 certifies the complete controlled runtime path as one integration:

`Decision -> Safety/Permission -> State/Recovery -> NosTale Sandbox -> Observation/Telemetry -> Audit/Test Center`

## Certified scenarios

- allowlisted sandbox command reaches simulation;
- non-allowlisted command is denied;
- fault transitions through recovery into SAFE;
- close reaches terminal CLOSED state;
- telemetry records the integrated command/recovery flow;
- real execution remains disabled and the kill-switch remains engaged.

## Exit criteria

All repository CI quality, regression, safety, dependency, benchmark and Test
Center E2E gates must be green before merge. This gate provides no authorization
for real NosTale execution.
